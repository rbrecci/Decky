Suporte

Encontrou um problema? Abra uma issue no repositório do Decky. Informe a versão do app, o aparelho ou navegador, o que aconteceu e os passos para reproduzir.

Proteja seus dados

Issues são públicas. Não envie e-mail pessoal, senha, tokens, links de recuperação nem capturas com dados de conta. Para pedidos de exclusão ou acesso aos seus dados, peça primeiro um canal privado ao responsável pelo projeto.

Problemas de acesso

Use "Esqueci minha senha" no login para recuperar uma conta por e-mail. Se você usa Google, tente "Entrar com Google". A senha do Google só pode ser recuperada no próprio Google.

Instalação

O APK é exclusivo para Android. No iPhone ou computador, jogue no navegador. Todos os aparelhos precisam de internet.
